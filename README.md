# 💬 Messaging Platform with Weather Dashboard

A modern, fully-functional web messaging platform with real-time messaging, user discovery, and an integrated weather dashboard.

## 🚀 Live Demo

**Access the platform here:** 
👉 https://vetrivignesh25-alt.github.io/mess-platform/

## ✨ Features

### Messaging Platform
- **User Registration** - Sign up with username & passcode
- **User Discovery** - Find and add people by username
- **Real-time Messaging** - Send and receive messages instantly
- **Conversation History** - All messages are saved locally
- **Beautiful UI** - Modern gradient design with smooth animations

### Weather Dashboard
- **Real-time Weather Data** - Uses OpenWeatherMap API
- **Current Weather** - Temperature, conditions, humidity, wind speed
- **Location-Based** - Get weather for your current location
- **City Search** - Search weather for any city
- **5-Day Forecast** - See upcoming weather predictions
- **Responsive Design** - Works on all devices

## 🛠️ How to Use

1. **Open the live platform:** https://vetrivignesh25-alt.github.io/mess-platform/
2. **Sign up** with a username and passcode
3. **Explore:**
   - Search for other users to message
   - Add contacts and start chatting
   - Switch to weather dashboard to check weather

## 💾 Data Storage

- All data is stored locally in your browser (localStorage)
- Messages and accounts persist across browser sessions
- No server required - fully client-side application
